8. Raw request lab

For the tricky stuff (double slashes, ../, percent-encoding, missing Host header), use curl / netcat instead of the browser — the browser normalizes URLs before sending them.

curl -v http://localhost:8080/a%2e%2e/
printf 'GET / HTTP/1.1\r\n\r\n' | nc localhost 8080
